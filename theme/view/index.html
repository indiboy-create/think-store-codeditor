Features

为模板编辑准备的能力

页面、接口与静态资源全部由包内提供，主项目不需要复制视图或资源文件。

进入编辑器

包内视图

theme/view 下的模板由包内 View 渲染器通过 think-view 输出，三页各自完整，公共头部与页脚按页面内联。

topthink/think-view · 缓存前缀 codeditor_

模板编辑器

Ace Editor 的 ace/mode/php 模式，支持 HTML 与 PHP 混合高亮、自动换行、行号与括号匹配。

GET {$templateApi}/read · POST {$templateApi}/update

分类管理

layui 数据表格展示分类，支持新增、编辑、删除与排序，操作人与站点由主项目 Session 统一提供。

GET {$categoryApi}/read · POST {$categoryApi}/create

编辑历史

保存时写入完整内容快照，使用 newstext_hash 去重；历史面板支持查看快照与一键还原。

GET {$templateApi}/history · POST {$templateApi}/history/restore
Endpoints

路由与接口

路由由服务提供者在 boot 阶段注册，宿主项目无需复制路由文件。

默认前缀 /store/think-store-codeditor
路由清单 --

方法 路径 名称 类型

路由前缀由 config/store_codeditor.php 的 route.prefix 与 route.segment 控制；静态资源由 {$assets}/<path> 直接输出，无需发布到 public。

安装与部署

需要 PHP 8.0 及以上与 ThinkPHP 8 主项目；服务会自动注册路由与配置，页面与静态资源均无需复制到主项目。

01

安装扩展

在主项目执行 composer require youvision/think-store-codeditor，topthink/think-view 会随依赖自动安装。

02

注册服务

通常由 post-autoload-dump 自动执行 service:discover 与 vendor:publish；未配置脚本时请手动执行。

03

打开编辑器

访问 {$template} 选择模板开始编辑，分类维护位于 {$category}。

04

静态资源

layui、Ace 与页面样式由 {$assets}/<path> 直接输出，无需发布到 public。

配置项

包内默认配置会与主项目配置合并，项目侧配置优先；修改后清除 runtime 缓存即可生效。

配置项 说明
route.prefix 默认 store。路由前缀，留空表示不添加前缀。
route.segment 默认 think-store-codeditor。包内命名空间，留空表示直接挂在路由前缀下。
route.middleware 默认 []。应用到整组路由的中间件，生产环境请接入主项目鉴权。
database.table 默认 template。模板数据表名，不含表前缀，读取 id、title、cid 等固定字段。
history.limit 默认 50。每个模板保留的最近快照条数，0 表示不裁剪。
file.root 默认 template。仅在新增模板创建文件时生效，配合 file.allow_dirs 与 file.ext 白名单。
安全与缓存

模板内容可直接写入数据库与受限目录，生产环境请按需限制访问。

  • 为 route.middleware 配置登录鉴权中间件，避免模板被匿名修改。
  • 文件写入受 file.root、file.allow_dirs、file.ext 限制，路径经过校验并拒绝目录穿越；file.overwrite 为 false 时不会覆盖已有文件。
  • 历史快照写入 database.history_table，使用 newstext_hash 去重，history.limit 控制保留条数。
  • 模板编译缓存写入主项目 runtime/temp/codeditor_*.php；修改模板未生效时清理缓存或执行 php think clear。
