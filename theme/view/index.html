Features

为模板编辑准备的能力

页面、接口与静态资源全部由包内提供，主项目不需要复制视图或资源文件。

进入编辑器

包内视图

theme/view 下的模板由包内 View 渲染器通过 think-view 输出，介绍页、编辑器页与分类页复用 layout 片段。

topthink/think-view · 缓存前缀 codeditor_

模板编辑器

Ace Editor 的 ace/mode/php 模式，支持 HTML 与 PHP 混合高亮、自动换行、行号与括号匹配。

GET {$templateApi}/read · POST {$templateApi}/update

分类管理

layui 数据表格展示分类，支持新增、编辑、删除与排序，操作人与站点由主项目 Session 统一提供。

GET {$categoryApi}/read · POST {$categoryApi}/create

编辑历史

保存时写入完整内容快照，使用 newstext_hash 去重；历史抽屉支持查看快照与一键还原。

GET {$templateApi}/history · POST {$templateApi}/history/restore

Workflow

一次编辑，四个环节

从模板列表进入编辑器，保存时写入快照，历史面板随时回看与还原，全流程留在包内完成。

选择模板

左侧数据表格按 ID、标题或分类筛选，点击即加载内容。

GET {$templateApi}/read?id=1

编辑内容

Ace 提供 HTML + PHP 混合高亮，Ctrl-S 直接保存。

ace/mode/php

保存快照

更新模板的同时写入完整快照，内容未变化则跳过。

POST {$templateApi}/update

回看与还原

历史面板按时间列出快照，可查看原文并一键还原。

POST {$templateApi}/history/restore
