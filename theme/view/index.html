youvision/think-store-codeditor

ThinkPHP 8 模板代码编辑器

在浏览器中编辑 HTML + PHP 混合模板：包内 think-view 渲染页面，Ace 提供混合高亮， layui 数据表格管理模板与分类，编辑历史支持查看与还原。

打开模板编辑器 分类管理

包内视图

theme/view 下的模板由包内 View 渲染器通过 think-view 直接输出，主项目不需要复制视图文件。

topthink/think-view · 缓存前缀 codeditor_

包内静态资源

layui、Ace 与页面资源由 assets 路由直接读取 theme/assets 输出，路径经过 realpath 校验并拒绝目录穿越。

{$assets}/<path> · 缓存 1 天

模板与分类

模板列表只返回 id、title、cid，不读取 newstext；分类独立管理，分类表为 template_category。

GET {$templateApi}/read · GET {$categoryApi}/read

编辑历史

每次保存写入完整内容快照，使用 newstext_hash 去重；历史抽屉支持查看与还原。

GET {$templateApi}/history · POST {$templateApi}/history/restore
